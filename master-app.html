Privacy & security

This website and its source files are public. Do not place passwords, account numbers, private documents, API secrets, or other sensitive information directly inside the published HTML files. Supabase-connected information is protected by your sign-in and database security rules.

Protect your data

Each tool manages its own information. Use the backup or export feature inside every app regularly, and keep the downloaded copies somewhere safe. A GitHub update replaces app files but does not replace a personal data backup.

How storage works: My Life Command Center and Retirement & Credit save locally first and can synchronize through Supabase after sign-in. The other tools primarily store information in this browser on this device. Clearing browser data may remove local information that has not been backed up or synchronized.
